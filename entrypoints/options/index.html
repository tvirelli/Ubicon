GitHub sync

See the same icons in every browser you use. Ubicon saves your icon choices and custom icons to a private folder in your own GitHub account, and each browser you connect reads from it.

  • Optional. Ubicon works exactly as before without it.
  • Free. A free GitHub account is enough.
  • Ubicon can only ever see that one private folder, and its author receives nothing.

Questions first? Read the GitHub sync guide: tokens, view-only access, multiple browsers, what is in the repository, and troubleshooting.

Your private folder: View-only

This browser is connected with a view-only token. It shows the synced icons and receives updates, but icons cannot be changed here.

Replace token

Paste a new token for the same private folder. Use this when the old token expired or was deleted on GitHub. Create a new token on GitHub, and remember to set Repository access to Only select repositories.

    Disconnect this browser?

    • Only this browser is affected. Your other browsers keep syncing.
    • Your icons stay in this browser.
    • The GitHub repo is not touched.

    This browser is disconnected. If you no longer want the data on GitHub, you can delete the folder from its settings page (Danger Zone, Delete this repository) and delete the token from your token list. Skip this if other browsers still use them.

      Sync your icons through GitHub

      Your icon choices and custom icons are saved to a private folder in your own GitHub account. Every browser you connect shows the same icons.

      What will happen
      You create a private folder on GitHub, then a key that opens only that folder, and paste the key here. Two GitHub pages open with their forms already filled in.
      What it costs
      Nothing. A free GitHub account is enough.
      What Ubicon will be able to see
      Only that one folder. Ubicon refuses any key that opens more than that. Nothing is sent to Ubicon's author.

      Create your private folder

      GitHub calls it a repository, or repo: a private folder on GitHub that only you can see. Ubicon keeps your icon choices in it. The form arrives filled in, so there is nothing to type.

      On the GitHub page

      1. Check that Repository name says ubicon-sync.
      2. Check that Private is selected.
      3. Click Create repository, then come back to this tab.

      If GitHub asks you to sign in first, sign in and the filled-in form appears next.

      Create your access token

      A token is a key that lets Ubicon save to that one folder and nothing else. GitHub fills in most of the form, but one setting you have to change yourself.

      !

      On the GitHub page, change Repository access to Only select repositories and pick ubicon-sync. Ubicon will refuse a token that can reach your other repos.

      On the GitHub page

      1. Under Repository access, choose Only select repositories.
      2. Click Select repositories and pick ubicon-sync.
      3. Scroll to the bottom and click Generate token. If GitHub shows a summary, click Generate token again.
      4. Click the copy icon next to the new token, then come back to this tab. GitHub shows the token only once.

      Paste your token

      Paste the token you just copied on GitHub. It starts with github_pat_. Ubicon checks it before saving anything.
